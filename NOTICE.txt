PC Mieru - third-party notices
==============================

This folder is self-contained: it carries the .NET runtime, so no separate
.NET installation is needed.

.NET runtime and Windows Desktop runtime (WinForms)
  Copyright (c) .NET Foundation and Contributors. MIT License.
  https://github.com/dotnet/runtime , https://github.com/dotnet/winforms

PC Mieru has no other third-party runtime dependency (no NuGet package is
shipped; every native call is a P/Invoke into a Windows system DLL, and the
vendor GPU libraries nvml.dll and amdadlx64.dll are loaded from System32 at
run time and are not redistributed here).
